How It Works

• Algorithm: AES-256-GCM (authenticated encryption)
• Key derivation: PBKDF2 with SHA-256, configurable iterations
• Salt: 16 random bytes, unique per encryption
• IV: 12 random bytes per encryption
• File format: Encrypted files use a self-contained .enc binary format that embeds salt, IV, iterations, and original filename
• Privacy: All operations happen locally in your browser. No data is sent anywhere.
